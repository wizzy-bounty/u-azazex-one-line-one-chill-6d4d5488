A make.fun entry for **One Line, One Chill** (`u-azazex-one-line-one-chill-6d4d5488`).

One sentence of horror, built to frighten in a single breath: a stranger who
appears in every holiday photo from last summer, standing a little closer to
the camera in each one — in pictures the narrator took alone. `main.py`
(Python stdlib only, deterministic, no network) writes the line to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Entry text

> Every photo on my phone from last summer has one extra person in it, standing a little closer to the camera in each one, and I took them all alone.
